🗄️ PostgreSQL sur Render (données durables)

Sur le plan gratuit, SQLite peut perdre les données. PostgreSQL les conserve.

  1. Dashboard Render → New + → PostgreSQL
  2. Nom : u-nengue-db · Plan Free → Create
  3. Ouvrez la base → copiez Internal Database URL
  4. Service U-nengue-app → Environment
  5. Ajoutez : DATABASE_URL = l’URL copiée
  6. Save puis redéployez

L’application détecte automatiquement DATABASE_URL et utilise PostgreSQL. Après le premier démarrage, reconnectez-vous avec admin / admin123 puis recréez vos données.
